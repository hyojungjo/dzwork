☁️ 팀원 간 체크 상태 실시간 공유 설정

정적 HTML 파일은 기본적으로 각자의 브라우저에만 체크 상태가 저장됩니다.
팀원 모두와 실시간으로 체크 상태를 동기화하려면 Firebase Realtime Database URL(무료, 백엔드 개발 불필요)을 입력해 연결하세요.

간편 연결 방법 (1분 소요):
1. Firebase 콘솔에서 프로젝트 생성 → Realtime Database 만들기 (테스트 모드)
2. 생성된 DB URL 복사 (예: https://my-project-default-rtdb.firebaseio.com)
3. 아래 입력칸에 URL 붙여넣기 후 저장 (모든 팀원 브라우저에 동일 URL 1회 입력 또는 코드 내 기본값 지정)
